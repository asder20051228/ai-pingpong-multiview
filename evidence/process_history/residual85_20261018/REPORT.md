# 冻结85之后：4070正式入口全量实验

## 结论

最终新方案：**86 TP / 1 FP / 6 FN，71.3854/75**。相对冻结85版本的70.0954/75，增加1.2900分，补回1个漏检、去掉3个误检。

原85个有效命中的预测帧号与坐标全部原样保留。最终方案3次正式全量运行预测文件SHA256相同，并与离线方案的每个输出坐标完全一致。

4070最终FPS分别为 **33.3, 33.7, 33.3**，中位数 **33.3 FPS**。旧85版本此前3次35.5、35.7、35.5 FPS，本轮计时复现35.7 FPS。颜色处理有少量额外耗时。

**精度最高与综合分最高需分开选择。** 依据赛题速度公式`1 + (FPS−1)×24/49`、50FPS封顶25分，使用当前4070三次测量中位数折算：不加颜色的轨迹组合速度 **35.9 FPS**，总分约 **89.15/100**；加入颜色的最高精度方案总分约 **88.21/100**。两个方案的各自3次预测均字节一致。这是本机公开集估算；正式4090上应重测再选。因此同时保留`candidate_solution:Solution`（86/2/6）和`final_solution:Solution`（86/1/6），不将最高精度方案直接当作最高比赛总分方案。

这是同一公开验证集上的正式比赛入口复测、按冻结评分器计算的精度分；不是官方隐藏测试平台回传分。主表精度分不含25分速度分，上方综合分为本机折算估计。15段公开视频均已参与开发，本结果不能证明未知视频泛化提升。

## 4090速度下限如何估计

**没有实测4090，不能给保证下限。** 在CPU、存储、解码实现、软件及其他负载与4070测试相近的条件下，可按最终4070吞吐附近作为保守预算，约 **33 FPS**；不能承诺50 FPS。

不加颜色的轨迹组合可按约 **35 FPS** 做同条件保守预算。假设模型GPU段加速2倍，其估计吞吐为 **37.91 FPS**，同样不是4090实测值。

字节一致的冻结85计时剖析中，2109帧总推理时间59.1秒，球模型与球台模型的TensorRT执行及等待共 **6.349秒**，仅约10.7%。本轮新增操作主要是CPU上的图像缩小、颜色统计与轨迹规则，模型不变。

以最终3次中位耗时 **63.2秒** 为基准，保持其余 **56.851秒** 不变，仅假设模型GPU段变快：

`估计FPS = 2109 / (其余耗时 + 6.34865 / GPU段加速倍数)`

| 假设模型GPU段加速 | 条件估计FPS |
|---|---:|
| 1倍 | 33.37 |
| 1.5倍 | 34.53 |
| 2倍 | 35.13 |
| 3倍 | 35.77 |
| 模型GPU段耗时降为0 | 37.10 |

最后一行仅是“其余耗时固定”这一模型下的极限，不是4090硬件的理论上限；其余时间还包含GPU解码、数据传输和同步，并非全是CPU。4090上的CPU与解码性能也可能变化。双4090不会自动让当前串行单卡入口翻倍。

因此，更换4090之外，还需优化预处理、数据搬运、解码或后处理，才能更有把握接近50 FPS；当前尚未测试这些速度优化。
